# Color Garden

A playful color-mixing game for curious kids. Mix paints, discover new shades, and grow a garden of happy flowers.

**[Play Color Garden](https://xing5.github.io/color-garden/)**

## Play

- **Explorer:** two scoops, new color combinations.
- **Wizard:** three scoops, ratios and tints.
- **Master:** four scoops, more complex shades.
- **Just mix:** explore freely with two to four scoops.

Eight paints, 24 target shades, optional spoken prompts, gentle hints, and no timers or lost lives. Tapping the same paint adds another scoop. Equivalent recipes and very close shades count. Tap a paint friend or flower for a happy wiggle.

The mixing model is an illustrative paint playground. Real pigments can produce different shades depending on their strength and the amounts used.

## Run locally

Open `index.html` in a browser. No installation, build step, or server is required. The game has no external assets, accounts, ads, or tracking. Spoken prompts depend on browser voice availability.

Keyboard controls: Tab to a control, then Enter or Space to activate it. Reduced-motion preferences are respected.

## Hosting and editing

The complete game—including its artwork, styles, and scripts—is in `index.html`.

GitHub Pages serves the root of the `main` branch. The `.nojekyll` file keeps deployment static. Edit `index.html` and commit to `main` to update the published game.
